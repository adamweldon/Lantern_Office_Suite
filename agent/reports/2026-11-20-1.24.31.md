## What changed

- AI_STATION (new): MAKE STATION -- pumps, floats (with heights if given), the well, the inlet, the force main, the
  valves' kind and the control voltage, each a line, the rest the usual and said. Lantern draws the control circuit
  (MAKE CONTROL's alternating relay), the piping and the float levels from it, all with the same pumps and floats, and
  writes the parts list, how it works, the commissioning checks and what it does not know. A whole-station question is
  offered MAKE STATION alone and not split (an action with `whole: true`); asked beside another thing, the station's
  drawings are one part. The drawings' own blocks for a station question are read as the station. Chat shows the three
  drawings and the text; Open in Writer makes one document; each drawing opens in Draw; Save .pdf saves the text.
- AI_CONTROL: the usual four floats for a wet well's floatless duplex; of two alarm floats each keeps its own light.
- AI_ACTIONS: `grammarFor(kind)` (llama.cpp GBNF), sent only where Lantern asked for only a block and only to a
  llama.cpp server (AI_ENGINE's `AI.server.llama`); `fixKind`, `wholeFor`, `strayText`; `relevant()` offers a whole
  tool alone; the reply's text in a block's build context.
- AI_PARTS: a whole tool ends the split; the station's parts side by side merged into one.
- AI_PUMP_STATION: small mends (LSHH tags, a depth after a diameter, missing heights spread, inch marks, a label's
  digit). AI_BENCH: a station's drawings graded as the item's parts; grammar use in each row; the log's summary says
  which questions were held to a grammar.
- tools/gbnf_check.py: Lantern's grammars through llama.cpp's own parser (libllama of the kit's engine, a vocabulary
  file from llama.cpp's repository).
