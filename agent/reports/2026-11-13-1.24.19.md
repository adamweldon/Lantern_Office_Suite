# 2026-11-13 — 1.24.19: one link to get Lantern

Started from `lantern-1.24.18`. Adam asked how many steps it takes a person
to get Lantern running, and then (2026-11-13): "I share a link to someone and
when they click it it downloads an executable that checks what system it is
on and downloads runs everything else automatically from our github site (and
then from wikipedia etc.) ... in a way that allows the user to use lantern
(which works without an ai but could give a progress of ai downloading and
wikipedia downloading etc. in the background if the user tries to use those
features)". He said yes to: the Windows starter first, with the progress in
Lantern and the downloads in the background, then the Mac and Linux starters
and a "Get Lantern" page; the small model and the right-sized one fetched by
themselves, the encyclopedia and the books offered once inside Lantern with
their sizes.

## Steps for a person, before and now

| | Before (Lantern.zip) | Now (the link) |
|---|---|---|
| Windows | download zip, extract, find Install (Windows).bat, More info / Run anyway, popups, wait with its window open, Start Lantern, keep its window open | open the link (the download starts), open Get-Lantern.exe, More info / Run anyway (until signed); Lantern is open and usable; the AI arrives in the background |
| Mac | download, extract with care (no merge), Install (Mac).command, Open Anyway, popups, Start Lantern | open the link, open Lantern from Downloads, Open Anyway in Privacy & Security once |
| Linux | as Windows | open the link, `chmod +x` (shown), run |
| Phones | the website, Add to Home Screen | the same, with the taps on the page |

## What changed

- `tools/starter/` (Go, no dependencies): `main.go` (install, serve, plan,
  worker, the kit's setup and start scripts with no window, the `@@`
  progress, the proxy to the engine, status/choose/stop, idle stop, only
  Lantern's own pages heard), `sys_windows.go`, `sys_unix.go`.
- `src/lantern.inner.html`: module `LANTERN_SETUP` (corner button, list,
  offers, Stop; `Lantern.aiWaitNote`); `AI_ENGINE` answers with the note
  while the AI is coming; `AI_SERVER_WAIT_VIEW` stays in the corner under
  the starter.
- The kit: `@@FROM <url> <part>` from both setup scripts; `LANTERN_NO_PAUSE`
  and `NO_BROWSER` honoured by `start-lantern.bat`.
- `tools/pack_starter.py`; `site/get.html`; `.github/workflows/lantern-zip.yml`
  (the programs on the release, gh-pages the same version on a push to
  `main`); `.github/workflows/lantern-starter.yml` (the starter for real on
  Windows, a Mac and Linux, on `lantern-*` and `wip-*` pushes).
- READMEs: README.md "Get Lantern with one link", README.txt (the Lantern
  program in the folder), kit/README.txt (what the starter sets).
