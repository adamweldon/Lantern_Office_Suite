# 1.24.42 -- the Photo tile (2026-11-26)

## What Adam asked
2026-11-26: "say so and do what the person wants. Lantern should also offer the same for
photoshop." The first half was 1.24.41 (a PDF's maker's limits). This is the second: a
picture editor that does on the device, with no internet, what Photoshop does, as far as
arithmetic can.

## What changed
- A new tile, Photo, of 53 modules (PHOTO_*, GUIDE_PHOTO), each droppable. Layers, groups
  (nested, Pass Through), masks, clipping, 27 blending modes, History with the opening state
  kept; PSD/PSB both ways (layers, groups, masks, modes, the plain adjustment layers; 16- and
  32-bit files with their layers); TIFF both ways; PNG, JPEG, WebP, GIF (animated), BMP, SVG,
  PDF with the resolution kept; 34 tools (the Magnetic Lasso among them); 23 adjustments;
  39 filters (Lens Blur, Smart Sharpen), Liquify, Lens Correction; Content-Aware Fill
  (PatchMatch), healing, Content-Aware Scale (seam carving), Merge Exposures (exposure
  fusion), Stack Mode; ten layer styles; eight custom shapes; a Swatches panel; the Pen and
  its paths; Actions and Batch; the help (GUIDE_PHOTO).
- Against 57 things from Adobe's Photoshop user guide: before, none and 7 in part; now 36,
  14 in part, 4 not, 3 that need Adobe's servers.
- CHANGELOG has the whole list and every mend.

  the mended build; 7 now, each kept with its reason (most: checks written for commands
  running during Free Transform, where nothing runs now).
- All four replayed by tests/review_photo_1242.py (in npm test): 1,451 checks, 28 kept
  failing, any other failure fails it.
